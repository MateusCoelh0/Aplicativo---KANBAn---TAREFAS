## ⚡ COMECE AGORA (5 minutos)

### 1. Configure Email (Mailtrap)
```bash
# 1. Acesse https://mailtrap.io
# 2. Crie conta grátis
# 3. Copie credenciais SMTP
# 4. Cole em backend/.env
```

### 2. Inicie Servidores
```bash
# Terminal 1
cd backend && npm run dev

# Terminal 2
npm run dev
```

### 3. Teste
```
http://localhost:5173/register  ← Crie uma conta
https://mailtrap.io             ← Verifique email
http://localhost:5173/login     ← Faça login
```
